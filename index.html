FEATURES

一块屏幕解决的事，
不必再多一块。

手机负责内容与操作，车机负责显示与播放。两端安装同一个 APK，在互联中心选择角色，即可开始。

MUSIC

音乐同步播放

手机选曲，车机同步播放。音频分块传输到车机本地，车机没有这首歌也能放。

CAR

车机独立播放

每台车机可独立播放自己的歌单，互不打断。也支持多车机同步播放。

LOCK

锁屏 / 悬浮播放器

锁屏即播放器，悬浮窗随时呼出。不解锁也能切歌、暂停、调出互联入口。

MAP

高德地图导航

手机搜索目的地，一键发送到车机桌面。支持路线规划、地图选点与简化示意图。

LOCATION

双向位置共享

手机与车机互相查看位置，实时显示相距距离，约多久到达一目了然。

CALLS

来电与短信提醒

手机收到电话、短信或通知时，车机端同步提醒。需授予通知使用权与相关权限。

WECOM

企业微信通知

通过群机器人 Webhook 或自建应用，把消息推送到车机，开车时不错过重要信息。

SECURE

应用锁与隐私

4 位密码保护指定界面，关屏自动锁定。核心连接发生在局域网内。

MUSIC SYNC

手机负责选歌，
车机负责好听。

不需要车机预装歌曲，也不依赖蓝牙。手机把音频文件分块传到车机本地播放，即使车机曲库里没有这首歌，也能完整播放。

  • 同步播放：手机与车机同一首歌、同一进度，车内车外无缝衔接。
  • 独立播放：每台车机拥有自己的播放队列，最多同时连接 2 台。
  • 锁屏控制：锁屏与悬浮窗都能切歌，单曲循环、顺序播放自由切换。
  • 定时关闭：睡前或到站自动停止播放，不再担心忘记暂停。

支持从手机文件中选择曲目与文件夹，车机端自动缓存，可手动清理缓存。

NAVIGATION

目的地，
从手机滑到车机。

把高德地图接进互联链路：手机上搜索、地图选点或定位当前位置，确认后一键发送，车机桌面立即开始导航。

LOCK & PRIVACY

锁屏是入口，
也是最后一道门。

锁屏播放器让常用操作触手可及，应用锁则确保借出手机或临时离车时，敏感界面不会被随手打开。

  • 4 位数字密码：可为全部界面或指定界面启用，支持随时修改与清除。
  • 关屏自动锁定：密码保存后，屏幕熄灭即重新锁定应用。
  • 试错锁定：连续输错 5 次自动锁定一段时间，可自定义时长。
  • 本地直连：手机与车机通过局域网通信，不需要注册账号。

GET CONNECTED

三步，连上你的车。

手机端与车机端安装同一个 APK，在「互联中心」选择不同角色即可。建议两台设备连接同一 Wi-Fi，或车机连接手机热点，无需蓝牙。

接入同一网络

两台设备连接同一 Wi-Fi；没有 Wi-Fi 时，手机开启热点，车机连接该热点。可在设置中手动填写对方 IP。

扫码或自动发现

在手机端生成配对二维码，用另一台设备扫码；也可等待局域网自动发现，或复制配对链接。

选择角色，开始

分别在两台设备上选择「手机端」与「车机端」，连接成功后进入 互联中心，音乐、导航、位置即刻可用。

FAQ

常见问题

连接、播放与安装过程中最常遇到的几个问题。

需要蓝牙吗？两台设备必须连接同一个 Wi-Fi 吗？

不需要蓝牙。两台设备需要处于同一局域网：可以连接同一个 Wi-Fi，也可以由手机开启热点、车机连接该热点。若自动发现失败，可在设置中手动填写对方 IP 与端口。

车机上没有这首歌，也能播放吗？

可以。手机端会选择曲目并把音频文件分块传输到车机本地播放，因此车机曲库中没有该歌曲也能完整播放。车机端会保留缓存，可在设置中清理。

最多可以连接几台车机？

最多同时连接 2 台车机。每台车机可以选择同步播放，或独立播放各自的队列。

地图一直显示简化示意图，没有真实路线？

真实地图与路线规划需要在「互联设置」中填入高德开放平台的 Web 端 Key（JS API 2.0 还需安全密钥 securityJsCode）。未配置时应用会使用简化位置示意图，位置共享与距离计算仍然可用。

锁屏播放器不显示，或来电提醒没有同步？

请在系统设置中为应用开启「悬浮窗权限」与「通知使用权」，并允许后台运行、忽略电池优化。通知/短信/来电提醒还需要对应的通知、电话与短信权限。

忘记应用锁密码怎么办？

应用锁为本地 4 位密码，没有云端找回。可在系统设置中清除应用数据以重置（会同时清除本地设置与缓存），或重新安装应用。
